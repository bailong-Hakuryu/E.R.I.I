# E.R.I.I. Domain Model

本文记录 `v0.4.0` 方向的权威术语。标记为“规划”的概念尚未在 `v0.3.x` 完整实现。

## Character Blueprint（人设底色，规划）

用户导入的角色身份、价值观、语言风格和边界。原始文本是权威来源，运行时事件不能覆盖它。结构化编译结果可以重新生成，但不能反向改写原文。

## Persona Instance（关系人格实例，规划）

由人设底色在一段具体关系中实例化的人格。每个 `Agent × User` 拥有独立实例；不同关系可以从相同底色出发，但分别成长。

## Relationship（关系，规划）

由稳定 `relationship_id` 标识的共同生命线。显示名称和外部平台 ID 是可变映射，不作为数据库内部身份。

## Memory Event（历史事件，规划）

追加式记录的共同经历、陈述、承诺、冲突、修复或反思。历史事件与“当前相信什么”分离，除隐私删除外不通过覆盖抹去历史。

## Current Belief（当前认知，规划）

由历史事件计算出的 Agent 当前认知。认知可以被新证据更新，并保留来源、置信度和有效时间。

## Relationship State（关系状态，规划）

对熟悉度、信任、亲密、安全感和冲突张力等内部维度的可解释投影。普通变化自动、渐进且有限幅度；每次变化必须引用证据。

## Persona Change Proposal（人格变更提案，规划）

当候选变化触及人设底色或产生巨大跃迁时创建。未经明确确认不得进入有效人格。

## Recall Salience（召回显著性）

控制一段记忆在当前情境下多容易被想起。显著性衰减不表示事件没有发生、认知失效或关系影响被撤销。

## Episode / Relationship Chapter（情节与关系章节，规划）

从相关历史事件派生的分层摘要。摘要必须保留来源引用，并能在删除事件后重建。

## Signal（信号，规划）

承诺到期、纪念日或未完成事件产生的结构化提醒。E.R.I.I. 只向宿主 Agent 提供信号，不直接联系用户。
