## 🔧 集成示例

### Engine 集成

```python
from erii.core.logging import get_logger, get_audit_logger
from erii.errors import StorageError, RelationshipNotFoundError

class ERIIEngine:
    def __init__(self):
        self.logger = get_logger("erii.engine")
        self.audit = get_audit_logger()
    
    def initialize_relationship(self, agent, user, blueprint):
        try:
            self.logger.info("初始化关系", extra={'agent': agent})
            rel_id = self._do_init(agent, user, blueprint)
            self.audit.log_relationship_init(rel_id, agent, user)
            return rel_id
        except StorageError as e:
            self.logger.error(f"初始化失败: {e}")
            raise
```
