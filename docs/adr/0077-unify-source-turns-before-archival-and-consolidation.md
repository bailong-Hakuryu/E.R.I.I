# Unify source turns before archival and consolidation

One stable, relationship-scoped Source Turn is the canonical identity of a complete User and Agent interaction. Archival Submission and Source Adjudication Run remain separate processing lifecycles with different outcomes and authority, but both reference that same Source Turn; Timeline and MemoryNode remain retrieval or narrative artifacts, while only accepted Relationship Events become authoritative relationship history. This source unification precedes trustworthy archival, retry idempotency, and Episode or Relationship Chapter consolidation so those stages do not permanently encode the current split between `remember()` and relationship adjudication. ADR-0078 separately establishes that the canonical relationship-visible Source Transcript remains durable even when processing-specific payload copies are cleared, and ADR-0079 fixes which processing channels belong to the original source acceptance.
