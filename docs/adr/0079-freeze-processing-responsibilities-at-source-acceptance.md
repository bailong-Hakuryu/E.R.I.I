# Freeze processing responsibilities at source acceptance

E.R.I.I. first persists an open Turn Record and User message through Turn Opening. Source Acceptance later atomically appends the displayed Agent reply, its continuity assessment and delivery disposition, and an immutable Source Processing Plan, then seals the same stable identity as a completed Source Turn before any derived processing begins. The default plan declares every currently configured per-turn Memory Archival and Relationship Adjudication channel, while the host may explicitly omit either channel before completion; omitted or later-added work never silently mutates the accepted plan and instead receives a distinct processing identity. Each declared channel retains an independent observable outcome that distinguishes successful artifacts, a valid no-output result, and failure. A Source Turn is processed only after every declared channel reaches a successful terminal outcome, including valid no-output completion; a failure leaves the source stored but processing incomplete, never rolls back its transcript, and never erases a valid result committed by another channel. Open and abandoned Turn Records have no Source Processing Plan and do not enter these channels by default. Inner Review and Persona Growth operate on accepted formal history across turns and therefore do not block per-turn processing completion.
