# Preserve historical Persona Reflections and append later understanding

已接受的 Persona Reflection 是 Agent 当时理解关系事件的独立、不可变 Persona Reflection Record，不因模型或 Prompt 升级而重新生成。记录引用原 Relationship Event，并以最小 Reflection Context Provenance 保留生成时的人格与关系依据；当前 Recall Rendering 可以在不改变事实、情绪方向、强度和核心含义的前提下调整措辞。错误理解通过显式引用原 `reflection_id` 的 Reflection Correction 追加，新获得的视角通过同样可追溯的 Reinterpretation 追加，任何后续理解都不得覆盖过去或伪装成“当时一直如此”。
