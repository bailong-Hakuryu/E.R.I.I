# Bind canonical roles through explicit relationship premises

Each Agent × User relationship explicitly selects a fresh, address-only, or canonical-continuation premise, with fresh as the kernel default. Character source text may propose a canonical role binding but cannot silently apply it: address-only changes no history or intimacy, while canonical continuation imports source-marked Premise Experiences for that relationship alone; changing the premise later requires a new relationship or explicit migration rather than an ordinary conversation event.
