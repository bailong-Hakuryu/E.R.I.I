# Combine global reflection triggers with approved character sensitivities

A single universal importance rule would make every Persona Instance attend to
the same events in the same way. Letting the reflection model decide importance
afresh on every Turn would make triggering unstable and allow emotional wording
or User pressure to manufacture significance. E.R.I.I. therefore combines a
global structural floor with an approved Reflection Sensitivity Profile.

The global floor requests review for relationship formation or ending,
important commitment creation or breach, major boundary changes or violations,
direct core-identity or value conflicts, substantial persistent relationship
consequences, and materially evidenced departures from the character's prior
choices. These categories prevent structurally important events from being
silently skipped. They do not imply that the character cares, regrets or wants
repair; `stance_unformed` and `no_reflection` remain valid.

The Reflection Sensitivity Profile describes what this character is especially
likely to examine. Every entry is derived from and cites Character Blueprint
source spans, Formative Experience, approved Manifest claims or approved
Persona Growth. It may identify sensitivities around values, desires, fears,
boundaries, relationship meaning, first-time choices and value fulfillment or
conflict. The profile is versioned and approved with the Persona authority that
supports it; later approved Growth can add a new version prospectively.

The profile controls only whether the interpreter receives an opportunity to
review an accepted event. It cannot prescribe remorse, affection, forgiveness,
avoidance, repair, growth or any other result. A User message cannot add or
change a sensitivity, and User harm or satisfaction is not itself an importance
multiplier. The same event may therefore trigger deep review for one character
and produce no formal reflection for another without either result being less
valid.

Trigger evaluation is based on bounded event classifications and resolvable
profile references rather than a free-form model importance score. The exact
decision, when triggered, still belongs to the independent Persona Reflection
Interpreter and the character's frozen causal context.

## Consequences

Important structural events remain visible across all characters, while
character-specific inner attention stays grounded in imported persona material
and approved growth. Profile generation and approval must preserve source
citations and unknowns; silence in the source cannot be converted into an
invented psychological sensitivity. ADR-0105 requires multi-directional
coverage analysis so that profile generation does not default to trauma alone.
