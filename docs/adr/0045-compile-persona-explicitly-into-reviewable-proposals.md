# Compile persona explicitly into reviewable proposals

The next structured-recall stage includes an explicitly invoked Persona Compiler that reads the complete Character Blueprint and produces an untrusted, source-anchored Persona Compilation Proposal. It never runs as a relationship-initialization side effect or hidden background task, cannot approve its own output, and must pass deterministic citation, dependency, scope, applicability, and schema validation before an exact proposal revision may become the approved Manifest; advanced hosts may also supply schema-valid manifests directly.
