# Separate evidence, event summary, Persona Reflection, and state decision

E.R.I.I. 分别保存来源 Evidence、中性的事件事实摘要、符合 Character Blueprint 的第一人称 Persona Reflection，以及由规则计算的 Relationship Signal 裁决结果。该分离同时是一条处理边界：第一阶段只能从来源提取并裁决中性事件、证据和定性信号，第二阶段只能在事件已接受后解释角色当时如何理解它；反思失败不撤销事件，事件也不能借人格化文本补写来源中没有发生的事实。该分离允许不同角色对同一类互动产生不同而可信的叙述，同时防止角色化文本冒充用户原话或绕过确定性规则直接控制关系数值。
