# Record interaction turns in two durable phases

E.R.I.I. will refine the single Turn Recording boundary into one staged durable lifecycle. `begin_turn()` atomically creates an `open` Turn Record with a stable `turn_id`, relationship scope, the visible User message, and permitted Interaction Context Signals before reply generation, allowing pre-delivery evaluation to cite stable source material and preventing a crash from erasing an already sent message. `complete_turn()` atomically appends the reply actually shown to the User, its Reply Continuity Assessment and delivery disposition, and the immutable Source Processing Plan, then seals the record as a completed Source Turn eligible for Memory Archival and Relationship Adjudication. Retryable reply-generation or evaluation failures leave the record open; `abandon_turn()` is reserved for user cancellation, explicit host termination, or unrecoverable failure and retains the User message plus a sanitized reason without inventing an Agent reply or entering complete-turn processing by default. `record_turn()` remains a one-shot atomic convenience API for hosts that already possess both visible messages and writes the same ledger. Open, completed, and abandoned records therefore share one identity and transcript lifecycle rather than creating competing source systems.
