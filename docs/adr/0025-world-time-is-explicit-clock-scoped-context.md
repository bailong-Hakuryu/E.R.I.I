# World time is explicit clock-scoped context

World Time is an optional, host-supplied clock for the character's story world rather than an alias for system time. It carries a clock identity and may include a host-provided comparable value; E.R.I.I. may render an opaque world-time value, but it only derives ordering or due signals when the relevant values belong to the same clock and are explicitly comparable, preventing real time from silently rewriting fictional chronology.
