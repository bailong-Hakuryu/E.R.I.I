# Freeze the exact batch before granting a commit permit

After extraction, validation, sanitization, and stable artifact ID assignment, a Worker asks a Prepared Commit Queue to atomically store the exact Prepared Archival Batch and its digest while validating the current Processing Lease. Success establishes an immutable Commit Binding for `archival_id`, `attempt_id`, and that digest, then issues a time-bounded Commit Permit; an expired lease cannot bind a result, and every renewed permit must target that same batch. Storage publishes only under a currently valid permit, repeated recovery returns the same Artifact Manifest, and crashes after binding never invoke the extractor again. The public status remains `processing` during this internal commit phase, and neither lease tokens nor permits enter receipts or external APIs.
