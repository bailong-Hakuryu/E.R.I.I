# Approve persona interpretation as a versioned manifest

Deterministic source hashing, Markdown span parsing, exact citation validation, indexing, and cost measurement may run automatically, but semantic Persona Interpretation first forms a complete Persona Compilation Proposal. The user approves one exact manifest version after resolving highlighted core, relationship, safety, contradiction, and unsupported-inference risks; compiler or model upgrades only produce reviewable diffs and never replace an approved manifest or alter existing relationships automatically.
