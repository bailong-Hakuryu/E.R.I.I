# Retain complete source transcripts in the core

E.R.I.I. will durably retain, without automatic expiry, the relationship-visible messages of every Turn Record together with the metadata required to preserve order, scope, state, version, and provenance. A completed Source Turn contains both User and displayed Agent messages; an open or abandoned record may truthfully contain only the User message and never fabricates a reply. “Permanent” means surviving processing completion, restarts, migrations, and model upgrades until the data owner explicitly deletes the relationship or source; it does not mean undeletable storage, and an explicit export path remains required. A Source Transcript has the highest fidelity for what the parties actually expressed but no automatic interpretive authority: user claims are not thereby proven facts, Agent replies are not thereby valid characterization, and neither becomes long-term memory, authoritative relationship history, Persona Reflection, or Persona Growth without the corresponding extraction and adjudication. Recall uses structured artifacts by default and fetches transcript excerpts only when relevant, rather than injecting the entire history. Hidden system messages, complete prompts, model-internal reasoning, credentials, and tool output invisible to both parties are outside the transcript; queue-local Archival Payload remains temporary and its cleanup never deletes the canonical Source Transcript.
