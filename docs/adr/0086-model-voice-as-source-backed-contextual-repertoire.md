# Model voice as a source-backed contextual repertoire

E.R.I.I. will extend the existing approved `VOICE` Persona Interpretation and `SITUATIONAL` activation tier with Contextual Voice Patterns rather than introduce another persona authority layer. Each pattern describes an available expression register, typed activation conditions such as emotion, activity, relationship safety, communication modality, or environmental cue, exact source-span examples, its interpretation basis, and dependencies on approved voice claims or Formative Experiences. A single canonical example proves that the register can occur in its supported context but does not establish habitual frequency, make the quotation a reusable catchphrase, or reduce the character to a broad label; runtime delivery prefers the pattern's neutral description and expands exact wording only when directly relevant. Patterns retain Persona Scope: character-level linguistic material may generalize, canonical-relationship expression remains tied to that source relationship, and relationship tendencies activate only when the current Persona Instance independently satisfies the stated conditions. Names, intimacy, roles, and shared experiences from a source relationship never transfer merely because the same register becomes appropriate. Engine activates a pattern only through source-typed Interaction Context Signals and versioned deterministic matching, never because the reply model declares its own desired emotion. Continuity evaluation therefore treats a supported contextual-register activation as character-consistent even when its surface wording contrasts with the character's baseline voice.
