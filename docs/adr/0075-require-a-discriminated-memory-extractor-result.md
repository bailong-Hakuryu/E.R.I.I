# Require a discriminated memory extractor result

MemoryExtractorV1 returns a strict, unknown-field-rejecting Archival Extraction Decision for one existing Source Turn: `kind=artifacts` contains at least one optional Timeline candidate or Memory Candidate, while `kind=no_memory` contains no artifacts and an allowlisted reason code. Engine, never the extractor, assigns scope, stable IDs, UTC time, `source_turn_id`, `source_archival_id`, and Extractor Descriptor. One turn permits at most one Timeline candidate and sixteen Memory Candidates by default with a configurable ceiling and hard maximum of sixty-four; each content field is at most 4096 characters, with at most sixteen 64-character tags and finite bounded numeric values. Exceeding a boundary is an invalid extraction failure rather than silent truncation, and legacy string callables require a strict compatibility adapter that may truthfully identify itself as `unversioned`.
