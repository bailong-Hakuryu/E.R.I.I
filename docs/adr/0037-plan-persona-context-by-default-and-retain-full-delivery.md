# Plan persona context by default and retain full delivery

Normal recall uses planned persona delivery: a source-anchored Persona Interpretation keeps stable inner dynamics and the minimum meaning of Formative Experiences active, then expands relevant original spans for the current situation and budget. Hosts may explicitly request full delivery as a fidelity baseline or high-context mode, but the complete source is not injected by default; both modes use the same Persona Context Planner so relationship isolation, visibility, source provenance, and budget rules remain consistent.
