# Plan persona context by default and retain full delivery

Normal recall uses planned persona delivery: a source-anchored Persona Interpretation keeps stable inner dynamics and the minimum meaning of Formative Experiences active, then expands relevant original spans for the current situation and budget. Hosts may explicitly request full delivery as a fidelity baseline or high-context mode. When an approved Manifest is available, full delivery means every relationship-eligible Manifest item plus its exact supporting source spans; it does not inject unrelated canonical relationship spans. The immutable complete Blueprint remains available to its owner for verification and export, outside model-facing recall.

For compatibility, full delivery without an approved Manifest still returns the legacy unreviewed Blueprint and emits `legacy_unreviewed_full_persona`. That mode cannot guarantee relationship-scope isolation and must not be used as a production multi-user generation context. Planned delivery remains fail-closed without a Manifest. Both Manifest-backed modes use the same Persona Context Planner, visibility, provenance, and budget rules.
