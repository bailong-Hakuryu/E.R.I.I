# Deduplicate underlying experiences, not current interactions

宿主对同一来源身份和版本的技术重试必须返回既有 Decision Receipt，不产生任何新历史。后来重新提及同一历史发生实例时，既有 Relationship Event 只保留并结算一次，新材料通过 Event Corroboration 支持、补充或反驳它；围绕旧经历在当前发生的共同回忆、袒露、重新理解或纠正则可通过 Event Reference 形成独立候选并接受裁决。仅仅换一种说法不能重复改变关系状态，无法确定引用对象时也不得强制合并；误收的重复事件通过追加重复关联来停止投影影响，而不删除审计历史。
