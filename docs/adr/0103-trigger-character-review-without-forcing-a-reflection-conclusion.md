# Trigger character review without forcing a reflection conclusion

Important relationship events should not remain only external facts, because a
character-continuity kernel must give the Persona Instance an opportunity to
form its own understanding. Requiring a remorseful or reconciliatory reflection
after every harmful event would instead make the system author a morally
preferred inner life for the character.

A versioned Reflection Trigger Policy combines the global structural floor and
the approved character-specific sensitivity contract in ADR-0104. It requests a
formal Persona Reflection Decision for qualifying accepted events without
letting a transient model invent what the character should find important.
Triggering is affectively neutral: positive intimacy can be significant, while
anger or rejection is not significant merely because it is negative.

The strict decision union has three successful semantic outcomes:

- `reflection` contains a source-backed, character-consistent understanding and
  creates an immutable Persona Reflection Record;
- `stance_unformed` confirms that the event matters but the character has not
  formed a sufficiently grounded stance;
- `no_reflection` confirms that the event produces no formal character
  reflection.

Technical failure remains separate from all three. `stance_unformed` is not an
empty reflection and `no_reflection` is not a euphemism for failure. Neither
creates a placeholder Persona Reflection Record, authorizes Persona Growth,
generates an apology or changes Relationship State.

An unformed stance persists as an honest current projection until later accepted
events support explicit Reinterpretation. Elapsed time does not mature it, and
no hidden worker retries reflection in the background. The host may process a
newly accepted causal event through the normal lifecycle; it cannot repeatedly
resample the same frozen event merely to obtain a more convenient inner answer.

The trigger guarantees an opportunity for character review, not introspection
on demand. A character may remain uncertain, conflicted, avoidant, resolved in
its boundary, remorseful or uninterested only when that outcome is supported by
its own approved persona and history.

## Consequences

Important experiences can enter the character's internal continuity without a
template apology or compulsory growth arc. Storage and MemoryPack portability
must distinguish reflection, unformed stance, no reflection and failure so that
unknown interiority is never silently converted into a convenient conclusion.
