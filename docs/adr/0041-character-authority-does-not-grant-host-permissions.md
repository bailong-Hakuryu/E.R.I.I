# Character authority does not grant host permissions

Character Blueprint is authoritative about the character but cannot override host safety, authorization, privacy, tool permissions, or E.R.I.I. relationship and history invariants. Conflicting source text remains intact for fidelity and audit while its inapplicable permission-changing meaning is excluded; valid in-character boundary and refusal intent from the same passage may still enter Persona Interpretation, and full delivery presents the source as subordinate character material rather than elevating it to host authority.
