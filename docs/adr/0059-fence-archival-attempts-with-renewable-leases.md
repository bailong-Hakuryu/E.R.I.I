# Fence archival attempts with renewable leases

Each claimed archival execution receives an internal `attempt_id`, opaque `lease_token`, and renewable deadline; a Worker heartbeats while extracting, and failure or ordinary receipt mutation requires the current token. The lease permits an attempt to ask the Queue to durably freeze one Prepared Archival Batch and establish its immutable Commit Binding, but only a non-expired Commit Permit authorizes publication. Lease expiry before binding ends and counts the attempt, allowing a later claim while fencing the stale Worker from binding a result or changing state; after binding, recovery may renew publication authority only for the exact same batch. Receipts expose attempt count but never either token, and this ownership protocol does not by itself claim idempotency across duplicate host submissions.
