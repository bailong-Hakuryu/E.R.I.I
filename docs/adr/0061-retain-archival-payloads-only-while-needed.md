# Retain archival payloads only while needed

Conversation text copied into the task queue is temporary Archival Payload rather than the canonical chat record, long-term memory, or an audit log; the durable Source Transcript established by ADR-0078 remains separately available under its relationship scope. Before a Commit Binding exists, extraction work may retain the queue copy; binding clears it immediately because every later commit recovery must use the fixed Prepared Archival Batch and may not call the extractor again. A terminal pre-binding failure retains that copy for seven days by default, configurable from immediate erasure through a hard maximum of thirty days. The Prepared Archival Batch is cleared immediately after completion, or retained under the same bounded window after a terminal commit failure so manual retry can publish only that batch. Expiry records `payload_expired` or `prepared_batch_expired` and installs the required Commit Termination Fence for bound work; it never deletes the Source Transcript, an already committed batch, or formal relationship history, and an explicitly requested historical reprocessing run may later read the canonical transcript rather than revive an expired queue task.
