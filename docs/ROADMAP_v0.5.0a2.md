# E.R.I.I. v0.5.0a2 开发路线图

## 版本概览

**目标版本**: v0.5.0a2  
**基础版本**: v0.5.0a1 (2026-08-06)  
**预计完成**: 2026-08-15  
**版本定位**: Alpha - 生产环境准备与 API 扩展

## 开发目标

v0.5.0a2 专注于三个核心方向：
1. **生产环境准备**：完善安全性、日志、错误处理等生产必需功能
2. **API 生态扩展**：集成 Gemini API，丰富模型支持
3. **质量保障**：扩展测试覆盖、建立性能基线、完善文档

## 任务清单

### 优先级 P0 - 必须完成

#### 1. 生产环境优化：API 密钥管理
**目标**：实现符合安全最佳实践的密钥管理机制

**具体任务**：
- [ ] 创建 `erii/security/credential_manager.py` 模块
- [ ] 实现环境变量注入机制
- [ ] 添加密钥验证和格式检查
- [ ] 实现密钥脱敏日志输出
- [ ] 添加密钥泄露检测测试（CI 门禁）
- [ ] 更新所有 adapter 使用新的密钥管理接口
- [ ] 更新文档和示例代码

**验收标准**：
- ✓ 所有密钥仅从环境变量或 Secret Manager 读取
- ✓ 源码、文档、fixture、日志中无密钥字面量
- ✓ CI 包含密钥泄露检测门禁
- ✓ 提供详细的密钥管理文档

**预计工时**: 1-2 天

## 风险和依赖

### 风险
1. **Gemini API 稳定性**：可能遇到 API 限制或变更
   - 缓解：早期测试，准备降级方案
   
2. **性能优化范围**：可能需要大规模重构
   - 缓解：先做 profiling，聚焦高价值优化

3. **文档工作量**：可能低估文档编写时间
   - 缓解：边开发边写文档，不留到最后

### 外部依赖
- Gemini API 访问权限
- 测试环境和 API 配额
- 性能测试基础设施
