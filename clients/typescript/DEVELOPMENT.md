# E.R.I.I. TypeScript Client

Official TypeScript client for E.R.I.I. Agent Memory System.

## Development

### Setup

```bash
npm install
```

### Build

```bash
npm run build
```

### Test

```bash
npm test
```

### Lint

```bash
npm run lint
```

## Publishing

```bash
npm run prepublishOnly
npm publish
```

## Project Structure

```
clients/typescript/
├── src/
│   ├── index.ts           # Main client implementation
│   └── index.test.ts      # Unit tests
├── dist/                  # Compiled output (generated)

```
